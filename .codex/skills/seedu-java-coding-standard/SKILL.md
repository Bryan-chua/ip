# SE-EDU Java Coding Standard

Apply the SE-EDU basic and intermediate Java rules to every Java file in this repository. Preserve behavior and the user's requested design while making code conformant.

## Required workflow

1. Before working on Java code, read [references/java-coding-standard.md](references/java-coding-standard.md).
2. Apply every relevant rule to new and changed code. For a repository-wide cleanup, inspect all Java files.
3. Use the Google Java Style Guide only for topics the SE-EDU standard does not cover.
4. Before finishing, compile or test the affected code and review naming, layout, statements, and comments.
5. Report any rule that cannot be followed because it conflicts with an explicit requirement.

## Authority

This skill is based on the [SE-EDU Java coding standard (basic + intermediate)](https://se-education.org/guides/conventions/java/intermediate.html). The linked guide is authoritative if this local summary is ambiguous.
