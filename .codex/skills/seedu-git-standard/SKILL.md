# SE-EDU Git Standard

Apply the SE-EDU Git conventions to all commit messages and branch names in this repository.

## Required workflow

1. Before commit-message or branch-name work, read [references/git-standard.md](references/git-standard.md).
2. Inspect the actual staged diff before creating or finalizing a commit message.
3. Keep each commit cohesive. If a message becomes too broad, recommend a finer split without changing staging unless authorized.
4. Validate the subject and, for non-trivial commits, the body against the reference before committing.
5. Report any unavoidable exception caused by an explicit user requirement.

This skill does not authorize commits, amendments, branch creation, pushes, or history rewrites. Obtain that authority from the user's request.

## Authority

This skill is based on the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html). The linked guide is authoritative if this summary is ambiguous.
